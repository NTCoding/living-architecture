# Delivery planning

Draft `delivery.md` once dogfooding is approved. It is the last planning step.

## What the document must answer

- The milestones, in the order they ship, each with a title.
- The stories inside each milestone, each one small enough for 1 pull request.
- What depends on what, and what can run in parallel.
- What is deferred, and why.

## Checklist before you tell Nick it is ready

- [ ] Every story names the thing it changes.
- [ ] Every milestone can be shown to Nick on its own.
- [ ] Each open question is a `:::decision` block.
