# Solution exploration

Draft `solution-exploration.md` once the problem definition is approved.

## What the document must answer

- Which 2 or 3 shapes a solution could take, and what each one costs.
- What we would reuse, and what we would build.
- Which risks each shape carries, and how we would find out early.
- Which shape you would pick, and why.

## Checklist before you tell Nick it is ready

- [ ] Each option has a cost and a reason, not only a description.
- [ ] The doc says which option you recommend and what the other one costs.
- [ ] Nothing is decided until Nick answers the `:::decision` block.
- [ ] The options are grounded in this repo, not in the market in general.
